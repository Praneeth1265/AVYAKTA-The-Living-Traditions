1. Project Overview & Team Structure
Avyakta is a cultural multi-domain club that brings together students passionate about performing arts, design,
technology, event management, and more. This document defines the complete visual and functional design of
the Avyakta website — a digital home that mirrors the club's spirit: vibrant, inclusive, rooted in Indian culture,
and welcoming to new talent.

2. Design Philosophy & Visual Identity
The Avyakta website is designed to feel like stepping into a richly decorated cultural space — the warmth of a
festive evening, the elegance of Indian craftsmanship, and the energy of a college club that is actively doing
things. Every design decision is governed by three principles:
   Culturally Rooted: Indian motifs, patterns, and colour sensibilities inform every element without being
cliché or overwhelming.
   Energetically Welcoming: Animations, scroll interactions, and layout guide visitors toward participation
— joining, registering, volunteering.
   Functionally Clean: Ornament never obstructs usability. Information hierarchy is always clear.
The gold-and-emerald logo is the anchor. The website extends that palette into bronze, charcoal, deep crimson,
and muted warm whites — reminiscent of silk textiles, temple stone, and festival lights. Geometric
rangoli-inspired dividers, paisley micro-patterns in subtle backgrounds, and mandala-style loading spinners add
cultural texture without being kitschy.

4. Indian Design Elements & Motifs
Indian design influence should feel woven in — not pasted on. The following elements are to be implemented as
SVG/CSS components, ensuring scalability and performance.

Implementation Guidance

SVG geometric star/petal dividers (6–8 points) between page sections. Render in bronze with a subtle drop shadow. Animate in on scroll.

5. Navigation & Layout Architecture
Global Layout
The website uses a full-width layout with a fixed top navbar and a rich footer. Content sections are full-width with
max-width containers (1280px) centred inside. Vertical rhythm is governed by an 8px grid.
Navbar Design
The navbar is initially transparent over the hero, transitioning to charcoal with bronze border-bottom on scroll.
The Avyakta logo (gold + emerald) sits left. Navigation links animate in from the top with a staggered fade +
slide on open.
Nav Links: Gallery · Events · Registrations / Volunteer · Recruitment · Members
On mobile, the hamburger icon triggers a full-screen slide-over menu with a rangoli motif background and large,
spaced links. The menu close button is an animated X.
Note: The navbar must NOT include any link to the hidden admin dashboard.

7. Admin & Domain-Head Dashboard System
7.1 Architecture Overview
The dashboard system operates at a hidden URL not linked anywhere on the public website. All authentication
happens on this page. Two tiers of access exist: Admin (full) and Domain Head (scoped to their domain's recruit
data).
7.2 Hidden URL
/avyakta-control-[randomhash]
The URL segment is a random alphanumeric hash (e.g. /avyakta-control-x7k2m9p). It is shared only verbally or
via secure message to authorized personnel. There is NO link to this route from any public-facing page, nav,
footer, or sitemap.
7.3 Login System
Aspect
Details
Login Page Design
Dark charcoal fullscreen. Avyakta logo centred. Single card: email + password fields. BRONZE 'Enter' button. No 'Forgot Password' link visible (reduces attack surface — admin handles resets manually).
Admin Login
One superuser account. Always active. Full dashboard access.
Domain Head Logins
Multiple accounts, one per domain (e.g., design-head@avyakta, tech-head@avyakta). Accounts are DISABLED outside of recruitment season. Admin enables/disables them via Supabase Auth dashboard.
Session
JWT-based session via Supabase Auth. Session expires after 8 hours of inactivity.
Failed Attempts
After 5 failed attempts, IP is soft-blocked for 15 minutes (Supabase rate limiting).

8. Supabase Data Architecture
All dynamic data is stored in Supabase (PostgreSQL). The following tables define the schema. Supabase
Storage is used for images (gallery, member photos, event posters).
Table Name
Key Columns
announcements
id, title, body, type (enum: recruitment/event/general), is_active, expires_at,
created_at
events
id, slug, name, description (rich text), date, end_date, venue, category, poster_url,
is_past, created_at
recruitment_applicat
ions
id, name, srn, branch, class, section, domain (array), experience, links (jsonb:
[{type, url}]), status (enum), interview_slot (jsonb), created_at
registrations
id, event_id (FK→events), role (participant/volunteer), name, srn, branch, class,
section, phone, email, extra_fields (jsonb), created_at
gallery_images
id, event_id (FK→events), image_url, caption, display_order, uploaded_at
members
id, name, designation, section (enum:
founders/advisors/prev_heads/prev_members/current_core), photo_url, quote,
year, display_order
history_milestones
id, year, title, description, image_url, display_order
domain_heads
id, domain, supabase_user_id (FK→auth.users), is_active
Row-Level Security (RLS)
   Public (anon) can READ: events, gallery_images, history_milestones, members, announcements (where
is_active = true).
   Public can INSERT INTO: recruitment_applications, registrations.
   Domain heads can SELECT recruitment_applications WHERE domain = their domain only (enforced via
RLS policy referencing domain_heads table).
   Admin (service role key, never exposed to frontend) has full access via server-side API routes.

9. Animations & Interaction Design
Interaction
Specification
Page Load
Mandala SVG loader (rotate + fade out). Only on cold load.
Hero Kolam
CSS stroke-dashoffset animation traces kolam border on hero section load. Duration: 2.4s ease-in-out.
Scroll Reveal
Intersection Observer triggers 'slide-up + fade in' on all cards and timeline entries. Threshold: 0.15. One-time trigger.
Navbar Transition
Background + border transition on scroll (requestAnimationFrame, not scroll event).
Member Card Hover
scale(1.04) + box-shadow BRONZE glow + CSS rotateY(3deg) tilt. Transition: 0.25s ease.
Member Modal
scale(0.9→1) + opacity(0→1). Backdrop: blur(6px) + rgba(28,28,28,0.85). Duration: 0.3s.
Event Card Hover
scale(1.03) + jaali SVG overlay fades in (opacity 0→0.6). Duration: 0.3s.
Gallery Lightbox
Fade in. Arrow navigation with slide transition (translateX). Keyboard accessible.
Form Submit Success
Checkmark draw animation + 'Namaste ■' text fade-in.
Festival Particles
CSS/canvas floating coloured dots on Events page hero. Max 40 particles, requestAnimationFrame loop.
Horizontal Scroll Events
Snap-scroll on X axis. Scroll indicator dots with active state.
Announcement Popup
Slide up from bottom-right. Auto-dismiss after 8s with countdown indicator.
Note: All animations must respect prefers-reduced-motion: reduce CSS media query. If set, replace all transitions with instant
state changes.
